# Domain questions — service planning / documents
- Does every requirement trace to a user problem, and every core user problem to a requirement?
- Which user scenarios, edge cases or roles are missing?
- Is the MVP scope realistic, and is anything in "Must" actually optional?
- Personal data and security: what is collected, why, and is it minimal?
- Are success metrics measurable and tied to the goal?
- Are claims about competitors or the market backed by sources?
- Are assumptions marked as assumptions?
