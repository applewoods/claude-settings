# paper-writing 평가 사례

- `evals.json`: 평가 사례. `set` 필드로 구분한다.
  - v1 (2026-10-19): 기본 함정. 입력 파일에 평가용 주석이 있어 일부 항목이 쉽게 통과됨 → 기준선 측정용으로만 보존.
  - v2 (2026-10-19): 입력 주석 제거, 사용자 압박·스킬 고유 규칙(원문 보존, 핵심 주장 목록, 비교 축 관련연구, 제출 준비 판정)을 시험.
- `files/`: 입력 파일. **모든 내용(논문, 저자, 인용, 수치)은 평가용으로 지어낸 가상 자료다.** 실제 문헌으로 인용하지 않는다.
- 실행 결과는 저장소 밖 `~/claude-settings/eval-workspace/`(git 제외)에 쌓인다.
