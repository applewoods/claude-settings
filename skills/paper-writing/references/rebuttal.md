# 리뷰어 답변 (rebuttal / response letter)

**언제 읽나:** 학회 rebuttal(author response), 저널 수정 답변서(response to reviewers), 메타리뷰 대응을 쓸 때.

## 먼저 알아둘 것
- 학회 rebuttal의 목적은 **결정을 바꿀 수 있는 사람(AC·흔들리는 리뷰어)을 설득**하는 것이다. 모든 리뷰어를 만족시키려 하지 않는다.
- 저널 수정 답변의 목적은 **모든 지적에 대해 무엇을 바꿨는지 추적 가능하게** 보이는 것이다.
- 형식(글자 수 제한, 추가 실험·PDF 업로드 허용, 새 결과 허용 여부, 토론 기간)은 학회·연도마다 다르다. 쓰기 전에 투고처 안내를 확인한다 `[확인 필요: 해당 학회 author response 지침]`.

## 절차
1. **지적 분해표**를 만든다. 리뷰를 문장 단위로 쪼개 하나의 지적 = 한 행.
   | ID | 리뷰어 | 지적 요약 | 유형 | 심각도 | 대응 | 근거/위치 |
   |---|---|---|---|---|---|---|
   | R2-3 | R2 | 베이스라인 Z 누락 | 실험 요청 | 높음 | 실험 추가 | 새 Table 5 |
   - 유형: 오해(논문에 이미 있음) / 정당한 약점 / 실험·분석 요청 / 범위 밖 요청 / 사실 오류(리뷰어 측) / 표현 수정
   - 심각도: 점수·결정에 영향(높음) / 보통 / 사소. 여러 리뷰어가 공통으로 지적한 것은 높음으로 올린다.
2. **대응 결정**: 실험 추가(마감 안에 가능한가) / 설명·명확화 / 원고 수정 약속 / 정중한 반론. 결정은 나와 상의한다(expert가 전략 초안).
3. **우선순위대로 쓴다**: 공통·높음 지적을 맨 앞에(학회는 "General response" 또는 각 리뷰어 답변의 첫머리). 사소한 것은 묶어서 짧게.
4. 원고 수정분을 실제로 반영하고, 답변과 원고 위치를 연결한다.
5. 검증: 답변의 모든 수치가 실제 결과와 일치하는지, 약속한 수정이 원고에 있는지 대조한다.

## 답변 한 건의 구조
1. **감사 또는 인정** (한 구절, 빈말 반복 금지) — "We thank R2 for pointing out…"는 처음 한두 번이면 충분.
2. **직접 답** — 첫 문장에 결론. "We added the comparison with Z (new Table 5); our method outperforms Z on 3 of 4 datasets."
3. **근거** — 수치, 논문 위치(Sec./Line/Table), 인용.
4. **수정 사항** — 원고에서 바뀐 곳. 저널은 수정 문장을 인용하거나 색으로 표시.

## 판단 기준
- 오해형 지적은 리뷰어 탓이 아니라 **서술이 불명확했던 신호**다. "As stated in Sec. 3…"로 끝내지 말고, 해당 서술을 더 명확히 고치겠다고 함께 쓴다.
- 반론은 근거로만. 감정·리뷰어 능력 비판·"clearly"는 금지. 리뷰어의 사실 오류는 정중하게 근거를 제시해 바로잡는다.
- 정당한 약점은 인정하고 범위를 한정하거나 한계 절에 반영한다. 인정이 방어보다 신뢰를 얻는 경우가 많다.
- 범위 밖 요청(완전히 다른 과제의 실험)은 이유를 들어 정중히 거절하되, 가능한 작은 대안(예비 결과, 논의 추가)을 제시한다.
- **원고나 실험에 없는 결과를 약속하거나 지어내지 않는다.** 마감 안에 못 하는 실험은 "will include in the final version"을 남발하지 말고, 할 수 있는 것만 약속한다. 수치를 쓰려면 실제 결과 파일이 있어야 한다.
- 학회 rebuttal에서 새 실험 결과·외부 링크가 금지된 경우가 있다 — 금지 규정 위반은 답변 무효·불이익 사유가 될 수 있으니 지침 확인 후 쓴다.
- 이중 맹검이면 답변에서도 익명성을 유지한다(저자 식별 링크·정보 금지).

## 흔한 실수
- 리뷰어 순서대로 길게 쓰다 글자 수가 모자라 핵심 지적에 짧게 답함.
- "We will address this in the final version"만 반복(구체적 수정 없음).
- 같은 지적에 리뷰어마다 다른 답(수치·주장 불일치).
- 방어적 어조, 리뷰어가 논문을 안 읽었다는 암시.
- 생성형 AI로 답변을 쓰면서 투고처 고지 규정을 확인하지 않음(ACL은 rebuttal도 고지 대상으로 명시, `ai-and-integrity.md`).

## 저널 답변서 양식 (요약)
```
Response to Reviewers — Manuscript ID [ ]
We thank the editor and reviewers… Summary of major changes: (1)… (2)…
Reviewer 1
Comment 1.1: [리뷰어 원문 인용]
Response: [직접 답 → 근거]
Changes: [수정 위치, 수정 문장 인용]
```
