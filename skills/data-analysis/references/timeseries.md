# 시계열·센서 데이터

언제 읽나: 시계열 예측, 센서·웨어러블 신호 분류(윈도잉), 시간에 따라 모은 데이터를 분석할 때.

## 1. 먼저 과제를 구분한다
- **예측(forecasting)**: 과거로 미래 값을 맞힌다. 평가 = 미래 구간.
- **시계열 분류·회귀(윈도우 단위)**: 신호 구간 → 라벨(활동 인식, 이상 탐지). 평가 = 보통 새 피험자·새 세션.
- **시계열 통계 분석**: 개입 효과, 추세, 연관. 자기상관 때문에 일반 검정이 무효.

## 2. 분할과 평가
- **시간순 분할이 기본.** 무작위 분할·셔플 금지. 예측은 롤링(확장) 원점 평가: 학습 구간을 늘려 가며 다음 구간을 예측(`TimeSeriesSplit`, Hyndman & Athanasopoulos *FPP3* 5.10절의 time series cross-validation).
- 윈도우가 겹치거나 라벨이 미래 구간을 쓰면 경계에 **gap(purge)**을 둔다: 최소 윈도우 길이 + 예측 지평(horizon). `TimeSeriesSplit(gap=...)`.
- **피험자·기기 일반화**를 주장하면 피험자 분할(Leave-One-Subject-Out 또는 GroupKFold). 같은 사람의 데이터가 train/test에 섞이면 성능이 크게 과대 추정되는 것으로 알려져 있다(활동 인식 문헌).
- 순수 자기회귀 모형에 한해 일반 K-fold도 유효할 수 있다는 결과가 있지만(Bergmeir, Hyndman & Koo 2018), 외생 변수·비정상성·윈도우 겹침이 있으면 해당하지 않는다 → 기본은 시간순.
- 하이퍼파라미터 튜닝도 시간순 CV 안에서. 최종 test는 가장 마지막 구간 1회.

## 3. 윈도잉 규칙
1. 원 신호를 피험자·시간 기준으로 **먼저 분할**한다.
2. 그다음 각 쪽에서 따로 윈도우를 자른다(겹침 윈도우가 경계를 넘지 않게).
3. 정규화(z-score 등) 통계는 train에서 계산. 피험자별 정규화를 쓰면 test 피험자의 통계를 쓰는 것이 실제 배포에서 가능한지(보정 데이터가 있는지) 적는다.
4. 윈도우 라벨 규칙(다수결, 끝 시점, 순수 구간만)을 밝히고, 라벨 전환 구간을 버리면 버린 개수를 보고한다.
5. 필터(저역·대역 통과)는 **인과 필터**를 쓰거나, 비인과(zero-phase, `filtfilt`) 필터를 쓰면 실시간 배포와 다르다는 점과 경계 누수 가능성을 적는다.
6. 윈도우 길이·겹침 비율·샘플링 주파수·리샘플링 방법을 보고한다.

## 4. 정상성·자기상관
- 정상성 점검: 시각화(추세·계절·분산 변화) + ADF(`statsmodels.tsa.stattools.adfuller`, 귀무 = 단위근) 와 KPSS(`kpss`, 귀무 = 정상성)를 **함께** 본다. 둘의 귀무가설이 반대다.
- 비정상이면 차분·로그 변환·추세 제거 또는 그것을 다루는 모형.
- 잔차 자기상관: ACF/PACF 그림, Ljung–Box(`statsmodels.stats.diagnostic.acorr_ljungbox`).
- **자기상관이 있는 관측치에 t-검정·상관 검정을 그대로 쓰지 않는다.** 유효 표본 수가 줄어 p가 과소 추정된다. 대안: 블록 부트스트랩, HAC(Newey–West) 표준오차(`fit(cov_type='HAC', cov_kwds={'maxlags': L})`), 시계열 모형.
- 두 추세 시계열의 상관은 허위 상관이기 쉽다 → 차분 후 확인.

## 5. 예측 평가 지표와 베이스라인
- 베이스라인: **naive(마지막 값), 계절 naive(지난 주기 같은 시점), 이동평균, 단순 지수평활·ARIMA.** 딥러닝 예측 모델이 이들을 못 이기는 경우가 드물지 않다.
- 선형 모델 베이스라인도 넣는다(장기 예측에서 단순 선형 모델이 트랜스포머 계열과 경쟁적이었다는 보고: Zeng et al. 2023).
- 지표: MAE·RMSE(원 단위). 여러 시계열을 묶어 비교하면 **MASE**(naive 대비 척도화)가 척도 독립이다. MAPE는 0 근처 값에서 폭발하고 비대칭 → 피한다.
- 예측 지평(horizon)별로 성능을 보고한다.
- 두 예측 모델 비교: Diebold–Mariano 검정(작은 표본 보정 버전 [확인 필요: statsmodels에 내장 함수가 없음, 직접 구현 또는 다른 패키지]).
- 확률 예측이면 예측 구간 포함률(coverage)과 CRPS·pinball loss.

## 6. 센서 데이터 흔한 실수
- 같은 세션의 겹침 윈도우를 무작위 분할 → 99% 정확도.
- 결측·센서 끊김을 선형 보간하면서 미래 값을 사용(양방향 보간).
- 기기마다 샘플링 주파수가 다른데 맞추지 않음, 시각 동기화 오차를 무시.
- 피험자 수(독립 단위)는 10명인데 윈도우 수(수만)를 n으로 보고.
