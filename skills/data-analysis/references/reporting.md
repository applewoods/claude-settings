# 결과 보고: 재현성 체크리스트 · 표 · 그림

언제 읽나: 결과를 표·그림·요약으로 정리할 때, 실험 기록 구조를 정할 때, 논문 제출 전 재현성 점검을 할 때. 논문 문장 자체는 `paper-writing` 스킬.

## 1. 실험 기록 폴더 (`templates/run_logger.py`)
```
results/<YYYYMMDD-HHMMSS>_<실험명>/
  config.yaml        # 실제로 쓴 설정(기본값 포함, 명령줄 덮어쓰기 반영)
  meta.json          # git 커밋 해시·dirty 여부, 실행 명령, 시작·종료 시각, 호스트, 시드
  environment.yml    # conda env export (또는 pip freeze)
  metrics.csv        # 시드·fold별 원 점수(집계 전)
  log.txt
  figures/
```
- **집계 전 원 점수**를 저장한다. 평균만 남기면 나중에 쌍체 비교·CI를 못 한다.
- 실패·중단된 실행 폴더도 지우지 않고 남긴다(이유를 meta에 기록).
- git 작업 트리가 dirty(커밋 안 된 변경)이면 meta에 표시한다.
- 환경 고정: `conda env export --no-builds > environment.yml`(다른 OS 재현용), 완전 고정은 `conda list --explicit`. 패키지 이름·버전을 논문 부록에 쓴다.
- MLflow·W&B 같은 추적 도구는 사용자가 원할 때만. 기본은 위 폴더 구조.

## 2. 결과 표 기준 (`templates/aggregate_results.py`)
- CSV(원 수치, 반올림 없이) + 마크다운 표(보고용, 반올림).
- 열: 방법, 지표별 평균 ± SD, n(시드·fold 수). 비교 표에는 베이스라인 대비 쌍체 차이와 CI.
- 소수점 자릿수는 불확실성에 맞춘다: SD가 0.01 수준이면 소수 셋째 자리까지. 의미 없는 자릿수를 늘어놓지 않는다.
- 최고값 굵게 표시는 차이가 불확실성보다 클 때만 의미가 있다. 유의하지 않은 차이는 같은 그룹으로 표시하거나 주석.
- 표 아래 주석: 지표 정의, ± 의 의미(SD/SE/CI), 시드 수, 분할 방식, 검정 방법.

## 3. 그림 기준 (`templates/save_figure.py`)
- PDF(벡터) + PNG(300 dpi). 글꼴이 PDF에 임베드되게(`pdf.fonttype: 42`).
- 축 이름 + 단위, 범례, 읽을 수 있는 글자 크기(논문 칼럼 폭 기준 최종 크기에서 7~9pt 이상).
- **색만으로 구분하지 않는다**: 선 모양·마커·해칭 병행. 색맹 안전 팔레트(예: Okabe–Ito, matplotlib `tab10`보다 안전).
- 오차 막대·음영이 **SD, SE, 95% CI 중 무엇인지 캡션에 쓴다.**
- 막대그래프만 쓰지 말고 개별 점(시드·피험자)을 함께 보여 준다(strip/swarm + 평균·CI). 작은 n에서 막대는 분포를 숨긴다.
- y축을 0에서 시작하지 않으면 그 사실이 보이게. 이중 y축은 피한다.
- 혼동 행렬은 정규화 기준(행/열)을 밝힌다.

## 4. 요약 문단 형식
1. 무엇을 비교했나(데이터, 분석 단위와 n, 분할 방식).
2. 핵심 결과: 효과 크기 + 95% CI(+ 검정, 보정된 p).
3. 베이스라인 대비 위치.
4. 주장할 수 없는 것: 인과 아님, 일반화 범위, 탐색적 분석, 확인하지 못한 가정.

## 5. 재현성 체크리스트 (제출 전)
학회·저널 체크리스트(NeurIPS Paper Checklist, ML Reproducibility Checklist(Pineau et al. 2021), 과학 연구용 REFORMS(Kapoor et al. 2024), 임상 예측 모델은 TRIPOD+AI(2024))의 공통 항목을 줄였다. 투고처 체크리스트가 있으면 그것을 우선한다.
