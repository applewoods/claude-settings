# 모델·방법 간 비교: 시드 분산과 유의성

언제 읽나: "제안 방법이 베이스라인보다 낫다", "구성 요소 X가 기여한다"를 주장할 때. 코드: `templates/compare_models.py`.

## 1. 분산의 출처를 구분한다
- **시드 분산**: 초기화·데이터 순서·드롭아웃·증강의 무작위성.
- **데이터 분할 분산**: 어떤 샘플이 train/test에 들어갔는가. 작은 데이터에서는 보통 시드 분산보다 크다.
- **하이퍼파라미터 선택 분산**: 튜닝 결과 자체의 흔들림.
- 시드만 바꾸고 분할을 고정하면 분할 분산을 놓친다. 가능하면 **분할도 반복**(반복 CV 또는 여러 분할 시드)한다(Bouthillier et al. 2021).

## 2. 기본 규칙
- 여러 시드(기본 5개)로 돌려 평균 ± 표준편차를 보고한다. **SD(실행 간 흩어짐)와 SE·CI(평균의 불확실성)를 구분해 표기**한다.
- 시드 5개는 평균 추정에 넉넉한 수가 아니다. 쌍체 차이의 CI가 0이나 최소 의미 있는 차이에 걸치고 주장이 중요하면 시드를 늘린다(10~20).
- **쌍체(paired)로 비교한다**: 같은 시드·같은 fold·같은 test 샘플에서 A−B 차이를 계산하고, 그 차이의 평균과 CI를 보고한다. 독립 두 집단으로 비교하면 검정력이 낭비된다.
- 시드를 많이 돌리고 가장 좋은 시드만 보고하는 것은 금지(cherry-picking). 모든 실행을 보고한다.

## 3. 상황별 검정 선택
| 상황 | 방법 | 메모 |
|---|---|---|
| **하나의 데이터셋, k-fold CV(또는 반복 CV) 점수** | **보정된 반복 t-검정**(Nadeau & Bengio 2003): 분산에 (1/J + n_test/n_train)를 곱함 | 일반 쌍체 t-검정은 fold들이 학습 데이터를 공유해 독립이 아니므로 1종 오류가 커진다. `templates/compare_models.py` |
| 하나의 데이터셋, 계산 여유 있음 | 5×2cv 쌍체 t-검정(Dietterich 1998) | 5회 2-fold. 고전적이며 1종 오류가 낮다 |
| **고정된 test 세트 하나, 두 분류기** | McNemar 검정(예측 불일치 쌍), 또는 test 샘플 부트스트랩으로 지표 차이 CI | McNemar는 학습 무작위성을 반영하지 않는다 → 여러 시드와 함께 |
| 고정 test, 임의 지표(F1·AUC·BLEU 등) | **쌍체 부트스트랩**(test 샘플을 재추출해 A−B 차이 분포) 또는 근사 무작위화(approximate randomization) | NLP 관행(Koehn 2004; Dror et al. 2018) |
| 여러 시드 × 고정 분할 | 시드별 쌍체 차이의 평균과 CI(t 또는 부트스트랩) | 시드 수가 작으면 CI가 넓다 — 그대로 보고 |
| **여러 데이터셋에서 두 방법** | Wilcoxon 부호순위 검정(데이터셋 = 단위) | Demšar(2006). 데이터셋 수가 너무 적으면(≲5) 검정력이 거의 없다 |
| 여러 데이터셋에서 여러 방법 | Friedman 검정 → 사후 비교 | 평균 순위 기반 Nemenyi 사후검정은 비교 대상 집합에 따라 결과가 바뀌는 문제가 지적됨 → 쌍별 Wilcoxon + Holm 권장(Benavoli, Corani & Mangili 2016) |
| "A가 B보다 나을 확률"을 말하고 싶을 때 | 베이지안 상관 t-검정 / 계층 모형(Benavoli et al. 2017), ROPE 설정 | `baycomp` [설치 필요] |

- CV fold 점수들에 일반 독립·쌍체 t-검정을 쓰지 않는다. 쓰면 "유의"가 쉽게 나온다.
- 보정 t-검정도 근사다. 결론이 경계선이면 "차이가 작고 불확실하다"고 쓴다.
- 모델 여러 개를 한 베이스라인과 비교하면 다중 비교 보정(Holm)을 한다.

## 4. 실질적 차이 판단
- 통계적 유의 ≠ 의미 있는 개선. 데이터셋 크기가 크면 0.1%p도 유의하게 나온다.
- 미리 "의미 있는 최소 차이"를 정하고(예: 정확도 1%p), CI가 그 이상인지로 판단한다.
- 판단은 **쌍체 차이의 CI**로 한다. 각 모델의 개별 SD를 문턱으로 쓰지 않는다: 시드마다 두 모델이 함께 오르내리면 개별 SD가 커도 쌍체 차이는 일관되게 양수일 수 있다(그래서 쌍체로 비교한다). 차이 CI가 0을 포함하면 "차이의 방향을 확정할 수 없다(차이 95% CI: −0.3~+0.5%p)"처럼 쓰고 순위를 주장하지 않는다. "비슷하다·동등하다"는 CI 전체가 미리 정한 동등성 범위(±Δ) 안에 있을 때만 쓴다(`test-selection.md` 7절).

## 5. 보고 예
> 5개 시드 × 5-fold에서 제안 방법의 macro-F1은 0.812 ± 0.011(평균 ± SD), 베이스라인은 0.798 ± 0.013이었다. 쌍체 차이는 +0.014(95% CI 0.006–0.022, Nadeau–Bengio 보정 t-검정, p = 0.003).
