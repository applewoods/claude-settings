# 발표자료

## 1. 시작 전에 정할 것
- 청중(랩미팅·학회·기업·과제 평가)과 발표 시간, 질의응답 시간.
- 청중이 끝나고 기억할 메시지 1~3개. 슬라이드는 이 메시지를 위해 존재한다.
- 슬라이드 수의 출발점: 발표 시간(분)당 1장 안팎. 그림·데모가 많으면 줄인다. 청중이 정한 장수 제한이 있으면 그것을 따른다.

## 2. 구성 (먼저 슬라이드 목록을 보여 준다)
슬라이드 목록은 `번호 | 제목 문장 | 보여 줄 것(그림·표·수치) | 말할 것(한 줄)`로 만든다. 확인 후 내용을 채운다.
- 연구 발표: 문제·동기 → 핵심 아이디어(그림 1장) → 방법 → 결과(가장 중요한 1~2개) → 한계·다음 단계 → 메시지 요약.
- 랩미팅·진행 보고: 지난번 이후 한 일 → 결과 → 막힌 점 → 결정·조언이 필요한 것 → 다음 계획.
- 기업·협력 기관: 결론(무엇이 가능해졌나) → 근거(시연·수치) → 적용 방법·일정 → 요청 사항. 전문 용어를 줄인다.

## 3. 슬라이드 원칙
- **슬라이드 하나에 메시지 하나.** 제목은 주제어가 아니라 그 슬라이드의 결론 문장으로 쓴다("결과" ✗ → "오경보가 CNN-LSTM보다 10% 줄었다" ○).
- 본문 글자는 최소로. 문장 대신 그림·표·핵심 수치. 글머리표는 3~4개 이내, 한 줄 이내.
- 수치는 단위와 비교 기준을 함께. 그래프는 축 이름·단위, 강조할 막대·선만 색으로.
- 말로 할 설명은 발표자 노트에 둔다. 슬라이드에 대본을 붙이지 않는다.
- 모든 수치·그림은 출처(내 결과 파일, 인용 문헌)와 대조한다. 인용 그림은 출처를 슬라이드에 표시한다.

## 4. 파일
- `pptx` 스킬로 만든다. 연구실·학회 템플릿이 있으면 그것을 쓴다.
- 만든 뒤 슬라이드를 이미지로 확인해 글자 넘침, 그림 깨짐, 작은 글씨(대략 18pt 미만)를 고친다.

## 점검표
- [ ] 청중·시간·기억할 메시지가 정해져 있다.
- [ ] 슬라이드 목록(제목 문장)을 먼저 보여 줬다.
- [ ] 모든 슬라이드 제목이 결론 문장이다.
- [ ] 글머리표·글자 양이 기준 안이고, 설명은 발표자 노트에 있다.
- [ ] 수치·그림이 출처와 맞고, 슬라이드 수가 시간에 맞다.
