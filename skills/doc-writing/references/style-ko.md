# 한국어 업무 문서 문체

## 1. 개조식 규칙
- 수준 기호: `□`(대항목) → `○`(중항목) → `-`(세부) → `·`(나열). 한 문서 안에서 바꾸지 않는다. 기관 양식에 정해진 기호가 있으면 그것을 따른다.
- 종결: `~함`, `~임`, `~예정`, 명사형(`~구축`, `~확보`) 중 하나의 흐름으로 통일한다. `~했다/~한다`와 섞지 않는다.
- 대항목은 결론이나 요지를 먼저 쓰고, 하위 항목이 근거·세부를 받친다.
  - 나쁜 예: `□ 연구 배경` / `○ 최근 웨어러블 기기가 보급되면서...`
  - 좋은 예: `□ 기존 낙상 감지는 오경보가 많아 현장에서 꺼 두는 경우가 많음` / `○ 근거: ...`
- 한 항목 = 한 내용. 2줄을 넘으면 나누고, 같은 수준에 3~6개 항목이 오게 한다.
- 표로 쓸 수 있는 비교·일정·예산은 표로 쓴다. 문장으로 길게 나열하지 않는다.

## 2. 문장
- 주어와 서술어를 가깝게 둔다. 수식어를 앞에 길게 쌓지 않는다.
- "~하는 것이 필요함", "~에 대한 연구를 수행함"처럼 늘어진 표현은 줄인다 → "~해야 함", "~를 연구함".
- 피동(`~되어진다`, `~에 의해`)보다 능동을 쓴다.
- 같은 대상은 처음 정한 이름으로 끝까지 부른다(시스템/플랫폼/모델 혼용 금지).

## 3. 과장어 → 대체
| 쓰지 않음 | 대신 |
|---|---|
| 혁신적인, 획기적인 | 무엇이 달라졌는지 비교로: "기존 A 대비 B를 C% 줄임" |
| 세계 최초, 국내 유일 | 근거와 확인 범위를 밝히거나 뺀다: "조사한 범위(○○ DB, 20XX~20XX)에서 같은 방식은 확인되지 않음" |
| 극대화, 최적화(근거 없이) | 목표 수치: "처리 시간 30초 → 10초 이내" |
| 다양한, 효과적인, 고도화 | 구체 대상·지표로 바꾼다 |
| ~에 크게 기여할 것으로 기대됨 | 누가 무엇에 쓰는지: "○○ 연구실이 △△ 실험의 전처리에 사용" |

## 4. 영어 사용
- 원어 그대로: 고유명사, 제품·모델·라이브러리 이름, 분야 표준 용어(예: Transformer, F1-score).
- 우리말로: 일반 단어(이슈 → 문제, 리소스 → 자원·인력, 니즈 → 수요, 어프로치 → 접근 방법, 솔루션 → 방법·제품·시스템, 케어 → 돌봄·관리, 시너지 → 상승 효과(대개 근거가 없으니 뺀다), 레버리지·leverage → 활용, 인사이트 → 시사점).
- 고친 뒤 원문의 외래어를 하나씩 다시 찾아 남은 것이 없는지 확인한다. 남겨야 하는 고유 용어는 이유를 적는다.
- 약어는 처음 나올 때 `한국어(원어, 약어)`로 풀어 쓴다: "대조 학습(Contrastive Learning, CL)".
- 영어 문장이나 영어 조사를 섞지 않는다("~를 leverage하여" 금지).

## 5. 형식
- 굵게: 결론, 핵심 수치, 꼭 지킬 조건에만. 한 절에 2~3곳 이내.
- 이모지·장식 기호(✅, 🚀 등) 쓰지 않는다.
- 제목 단계는 3단계 이내. 한 줄짜리 목록을 잘게 쪼개지 않는다.
- 숫자: 천 단위 쉼표, 단위는 숫자 옆에 일관되게(백만 원, %, 개월). 소수 자릿수를 표 안에서 통일한다.

## 점검표
- [ ] 수준 기호와 종결어미가 문서 전체에서 통일돼 있다.
- [ ] 대항목이 요지를 먼저 말한다.
- [ ] 2줄 넘는 항목, 중복 설명이 없다.
- [ ] 3절의 과장어가 없거나 근거로 바뀌었다.
- [ ] 불필요한 영어가 없고, 약어는 첫 등장에 풀이됐다.
- [ ] 굵게·이모지·제목 단계가 5절 기준 안이다.
