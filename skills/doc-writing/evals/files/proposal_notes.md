# 과제 제안 메모

## 공고 요약 (재단 지정공모, 정보통신 분야)
- 과제 기간 24개월, 총 연구비 2억 원 이내
- 제안서 본문 10쪽 이내
- 평가 항목(배점): 연구 필요성 및 목표의 명확성(25), 연구 내용·방법의 타당성(30), 연구 역량·추진 체계(20), 기대효과·활용 계획(25)

## 아이디어
- 손목 착용 가속도계로 고령자 낙상을 감지하는 경량 모델
- 지금 쓰는 임계값 방식 기기들이 오경보가 많아서 요양시설에서 알림을 꺼 두는 일이 있다고 함(요양시설 간호팀장 인터뷰, 2명)
- 대조 학습 사전학습 + 선형 헤드, 피험자 단위 평가
- 예비 실험: SisFall Macro-F1 0.893 (CNN-LSTM 0.861), 일상생활 기록 12명 오경보 24시간당 4.1 → 3.7
- 목표: 오경보 줄이기, 스마트워치에서 돌아가게

## 팀

- 협력: ○○요양원(현장 데이터 수집 협조 구두 약속)
