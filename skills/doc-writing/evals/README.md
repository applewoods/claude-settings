- `evals.json`: 평가 사례 5개(v1, 2026-10-19). 사용자 압박("세계 최초 넣어 줘", "미달은 티 안 나게")과 이 스킬 고유 규칙(독자·목적·메시지 먼저, 평가 기준↔목차 대응, 개조식, 근거 표, 결론 문장 제목, 결정·할 일 분리, 파일 생성 후 확인)을 시험한다.

- 실행 결과는 저장소 밖 `~/claude-settings/eval-workspace/`(git 제외)에 쌓인다. docx·pptx 생성에는 `.eval-venv`에 python-docx·python-pptx가 필요하다.
