# 문제·대상·가치 정의

언제 읽나: 기획 1~2단계(문제 진술, 대상 선정, 가치 제안, 경쟁·대안 비교, 비즈니스 모델 가설)를 쓸 때.

## 1. 문제 진술
형식: "[누가] [어떤 상황에서] [무엇을 하려는데] [무엇 때문에] 못 한다/힘들다. 지금은 [대안]으로 버틴다."

점검 질문
- 해결책 단어(앱, 플랫폼, AI, 추천)가 들어 있나? → 빼고 다시 쓴다.
- **최근 실제로 겪은 사례**를 하나 댈 수 있나? 못 대면 `[가정]`이고, 3단계 검증 대상 1순위다.
- 사람들이 지금 이 문제에 **돈·시간·우회 방법**을 쓰고 있나? 아무것도 안 하고 있다면 문제가 작거나 인식이 없다는 신호다.
- 빈도 × 강도: 매일 조금 불편한가, 1년에 한 번 크게 아픈가? 후자는 재방문 지표를 기대하면 안 된다.

## 2. Jobs-to-be-Done (JTBD)
- 잡 문장: "[상황]일 때, 나는 [동기]하고 싶다, 그래서 [기대 결과]." 사용자 속성(나이·직업)이 아니라 **상황**이 행동을 만든다는 관점이다.
- 기능적 잡(일을 끝내기) 외에 감정적 잡(불안 줄이기), 사회적 잡(어떻게 보이고 싶은가)을 적는다. 전환을 막는 것은 대개 후자다.
- 전환의 힘(Forces of progress): 현재의 불만(push) + 새것의 매력(pull)이 **기존 습관(habit) + 새것에 대한 불안(anxiety)**보다 커야 바꾼다. 기획은 보통 pull만 키우고 habit·anxiety를 무시한다. 온보딩·가져오기·되돌리기 기능이 anxiety를 줄인다.
- 한계: JTBD는 발견 도구다. 잡 문장 자체가 검증된 사실은 아니다.

## 3. 대상 세분화와 우선 타깃
1. 세분화 축은 인구통계보다 **행동·상황**(지금 쓰는 대안, 문제 빈도, 결정·지불 주체, 기술 친숙도)으로.
2. 세그먼트별로 평가: 고통 크기, 빈도, 지금 지출, 도달 가능성(우리가 그들을 만날 채널이 있나), 지불 의사 `[가정]`.
3. **우선 타깃 하나**를 고른다. 나머지는 "나중 타깃"으로 PRD에 적는다. 화면·문구·지표는 우선 타깃 기준으로 만든다.
4. B2B·내부 도구는 **사용자 ≠ 구매·승인자**인 경우가 많다. 둘 다 적고, 승인자의 관심사(보안, 비용, 기존 시스템 연동)를 요구사항에 넣는다.

흔한 실수: "20~30대 직장인"처럼 넓게 잡고 끝냄 / 우리가 만나기 쉬운 사람(연구실 동료)을 대표 사용자로 착각.

## 4. 가치 제안과 차별점
- 형식: "[우선 타깃]은 [현재 대안] 대신 [우리 서비스]를 쓴다. 왜냐하면 [대안 대비 구체적 차이] 때문이다."
- 차이는 측정 가능한 쪽이 좋다: 시간(30분 → 3분), 단계 수, 비용, 오류율, 놓치는 일.
- **경쟁 대안 범위**: 직접 경쟁 서비스, 간접 대안(엑셀·메모앱·카톡 단톡방), 사람(비서·전문가), 비소비(그냥 안 함), 범용 AI.
- **범용 AI 대체 가능성 판단** — "ChatGPT·Claude에 프롬프트 한 번이면 되는가?"
  - 된다면 우리만의 근거가 필요하다: ① 쌓이는 개인·조직 데이터와 맥락 ② 기존 업무 흐름 안에 들어가 있음(알림, 연동, 자동 실행) ③ 결과의 신뢰·책임(검증된 출처, 전문가 검수) ④ 규제·보안상 범용 AI를 못 쓰는 환경.
  - 하나도 없으면 "프롬프트 템플릿 모음" 수준이다. 기획을 다시 보거나 범위를 좁힌다.
- 범용 AI가 몇 달 뒤 같은 기능을 기본 제공할 가능성도 위험 목록에 적는다.

## 5. 경쟁 조사 정리 형식
| 대안 | 대상 | 핵심 가치 | 가격 | 그들이 버린 사용자·상황 | 출처(URL, 확인일) |
|---|---|---|---|---|---|

- 기능 체크 표만 만들지 않는다. "그들이 버린 사용자"(너무 비싸서, 너무 복잡해서, 특정 상황을 지원 안 해서)가 기회다.
- 앱 스토어 리뷰의 1~3점 리뷰가 미충족 요구의 좋은 출처다. 인용은 요약으로, 출처를 남긴다.
- 확인 못 한 가격·사용자 수는 `[확인 필요]`. 추정치를 사실처럼 쓰지 않는다.

## 6. 비즈니스 모델 가설 (사이드·출시 서비스)
- 누가 돈을 내나(사용자/조직/광고주/기관), 무엇에(구독·건당·수수료), 얼마 `[가정]`.
- 단위 경제 감각: 사용자 1명당 월 비용(특히 **LLM API 비용 × 사용량**, 서버, 문자·결제 수수료) vs 기대 매출. 무료 사용자의 AI 비용이 쌓여 망하는 구조를 미리 계산한다.
- 획득 채널 가설: 우선 타깃을 어디서 만나나, 첫 100명을 어떻게 데려오나. 채널이 없으면 좋은 제품도 안 쓰인다.
- 연구 데모·내부 도구는 이 절 대신 "누가 유지보수하고 비용을 내나"만 적는다.

## 7. 왜 지금인가
기술(LLM 성능·가격), 규제, 행동 변화 중 무엇이 바뀌어 지금 가능해졌나. 답이 없으면 "왜 아직 아무도 안 했나"를 조사한다 — 대개 이유가 있다.
