# 응용·도메인 AI 체크리스트
의료·산업·교육 등 특정 분야에 AI를 적용한 논문. ML 체크리스트의 베이스라인·결과 신뢰도 항목도 함께 본다. 해당하는 항목만 쓰고, 각 지적에 결론이 어떻게 약해지는지를 붙인다.

## 데이터
- 출처·수집 기간·기관이 몇 곳인가. 한 기관 데이터면 다른 곳에서도 될지 모른다.
- 분할 단위가 맞나. 예: 환자·사용자·설비 단위가 아니라 이미지·샘플 단위로 나누면 같은 대상이 학습과 테스트에 모두 들어가 성능이 부풀려진다.
- 라벨은 어떻게 만들었나(전문가 수, 자동 추출, 라벨 노이즈). 정답 자체의 신뢰도가 성능의 상한이다.
- 외부 검증(다른 기관·시기 데이터)이 있나.

## 비교 대상
- 전문가와 비교했다면 전문가 수, 경력, 같은 정보·시간 조건이었는지. 조건이 다르면 "전문가 수준"이라는 주장이 약해진다.
- 현장에서 이미 쓰는 방법(규칙 기반, 기존 도구)과도 비교했나.

## 현장 의미
- 지표가 현장 결정과 연결되나. 예: AUROC만 있고 실제 운영 임계값에서의 민감도·특이도·오경보 수가 없다.
- 하위 집단(나이·성별·장비·지역)별 성능 차이를 봤나.
- 실제 배치 조건(입력 품질, 속도, 사람과의 협업 방식)을 고려했나.

## 윤리·규제
- IRB·데이터 사용 승인, 개인정보 처리가 명시됐나.
- 오작동 시 피해와 책임을 논의했나.
