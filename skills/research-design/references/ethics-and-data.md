# 연구 윤리 · IRB · 데이터 사용 권한 · 개인정보

**언제 읽나:** 인간 참여자(설문·인터뷰·사용자 평가·크라우드소싱 주석)가 있을 때, 개인정보·의료·학생 등 민감 데이터를 쓸 때, 웹 수집 데이터·외부 데이터셋·사전학습 모델의 사용 조건을 확인할 때, 투고처의 윤리 체크리스트를 채울 때.

> 법·규정 요약은 **2026-10-17 확인 기준**이며 법률 자문이 아니다. 최종 판단은 소속 기관 IRB·연구윤리 담당·데이터 제공자에게 받는다. 조문 세부는 국가법령정보센터 원문 확인 `[확인 필요]`.

## §1. IRB 대상인지 먼저 확인
- 국내 「생명윤리 및 안전에 관한 법률」의 **인간대상연구**는 기관 안내들에서 대체로 다음 세 유형으로 설명된다: ① 사람에게 물리적으로 개입하는 연구, ② 의사소통·대인 접촉 등 **상호작용**을 통한 연구(설문·인터뷰·사용자 실험 포함), ③ **개인을 식별할 수 있는 정보**를 이용하는 연구. 인간대상연구는 IRB 심의 대상이며, 법이 정한 기준에 따라 심의 면제가 될 수 있다(생명윤리법 제15조, 시행규칙 제13조 — 세부 요건 `[확인 필요: 조문 원문]`).
- **면제 여부는 연구자가 스스로 판단하지 않는다.** 많은 기관이 면제도 IRB에 신청해 확인받도록 한다. 소속 기관 절차를 확인한다.
- 흔히 IRB 확인이 필요한 AI 연구: 사용자 평가·A/B 실험, 인간 평가(주석·선호 판단)에 외부 참여자 모집, 설문·인터뷰, 의료·교육 기록, SNS·커뮤니티 글 중 개인 식별 가능 데이터.
- 흔히 해당하지 않는 연구(기관 안내 예): 알고리즘·공개 벤치마크만 쓰는 연구, 이미 비식별화되어 공개된 데이터만 쓰는 연구. 그래도 데이터 라이선스(§3)는 따로 확인한다.
- **심의 면제와 동의 면제는 별개다.** IRB 심의 면제를 받아도 참여자 설명·동의는 별도로 필요할 수 있다. 서면동의 면제에는 생명윤리법 제16조의 별도 요건과 기관위원회 승인이 필요하다 `[확인 필요: 조문 원문]`. 계획서에 ① 심의 대상/면제, ② 동의 취득 방식 또는 동의 면제 근거, ③ 동의 철회 절차, ④ 취약 참여자(미성년자 등)의 대리동의를 따로 기록한다.
- **승인 전에 데이터를 모으지 않는다.** 사후 승인은 대부분 불가능하며, 승인 없는 인간대상 데이터는 투고처 윤리 심사에서 문제가 된다.
- 해외 공동연구·해외 데이터: 상대 기관 IRB, 해당 국가 규정(예: 미국 Common Rule, EU GDPR) 적용 여부를 공동연구자와 확인.

## §2. 개인정보
- 국내 「개인정보 보호법」은 과학적 연구 목적 등으로 **가명정보**를 정보주체 동의 없이 처리할 수 있는 특례를 두지만(제28조의2 등), 가명처리 기준·결합·안전조치·재식별 금지 등 의무가 따른다 `[확인 필요: 현행 조문과 기관 가명정보 절차]`.
- 민감정보(건강, 생체인식 등)·고유식별정보는 더 엄격하다. 데이터 제공 기관의 심의·계약 조건을 따른다.
- 개인정보가 포함된 데이터를 **외부 LLM API에 보내는 것**은 처리위탁 또는 제3자 제공, 그리고 국외 이전(개인정보 보호법 제28조의8)에 해당할 수 있다. 계획 단계에서 다음을 **각각** 확인한다:
  1. 보낼 데이터가 익명정보인지, 가명정보인지(가명정보도 개인정보다 — 법 적용이 빠지지 않는다), 식별 가능한 개인정보인지.
  2. 위탁/제공 중 무엇인지와 그 법적 근거, 국외 이전이면 이전 근거와 보호조치(계약, 서비스 제공자의 데이터 보관·학습 사용 조건).
  3. 위가 해결되지 않으면 로컬 모델 사용 또는 익명화 후 전송으로 바꾼다.
  - **기관 IRB·내부 승인은 이 법적 요건을 검토하는 절차일 뿐, 그 자체로 국외 이전 근거가 아니다.** 세부 요건 `[확인 필요: 현행 조문·기관 개인정보 담당]`.
- 공개 논문·데이터 공개 시 재식별 위험(예시 문장, 희귀 속성 조합)을 점검한다.

## §3. 데이터·모델 사용 권한
| 대상 | 확인할 것 |
|---|---|
| 공개 데이터셋 | 라이선스(CC BY / BY-NC / BY-SA / 연구 전용 / 사용자 약관), 상업적 이용·재배포·파생 데이터 공개 허용 여부, 인용 요구 |
| 기관·기업 제공 데이터 | 데이터 사용 계약(DUA) 범위: 사용 목적, 기간, 논문 게재·예시 인용 허용, 코드·모델 공개 허용 |
| 웹 수집(크롤링) | 사이트 이용약관·robots.txt, 저작권(텍스트·이미지), 개인정보 포함 여부. "공개돼 있다"는 "써도 된다"가 아니다 |
| 사전학습 모델·API | 모델 라이선스(연구 전용·상업 제한·사용 정책), API 약관(출력물로 경쟁 모델 학습 금지 조항 등), 버전·접근 날짜 기록 |
| 크라우드소싱 주석 | 공정한 보상, 작업 내용 고지, 유해 콘텐츠 노출 시 사전 안내, 플랫폼 약관 |

- 확인 결과는 계획서의 윤리 절에 표로 남긴다. 확인 못 한 항목은 `[확인 필요]`로 남기고 데이터 사용 전에 해소한다.
- 새 데이터셋을 공개할 계획이면 데이터 카드(출처, 수집 방법, 동의, 라이선스, 알려진 편향, 의도된 용도와 부적절한 용도)를 계획에 넣는다.

## §4. 투고처의 윤리 요구
- AI 학회 다수가 윤리·재현성 체크리스트, 윤리 선언문(ethics statement), 한계·사회적 영향 절을 요구하거나 권장한다. 요구 항목과 분량 포함 여부는 해당 연도 CFP에서 확인 `[확인 필요]`.
- 인간 참여자 연구는 IRB 승인 번호(또는 면제 확인)와 참여자 보상·동의 절차를 논문에 쓰게 하는 곳이 많다 — 계획 단계에서 기록을 남겨 둔다.
- 이중 용도·오남용 위험(예: 탐지 회피, 개인 프로파일링)이 있는 연구는 위험과 완화책을 미리 적는다.

## §5. 연구 기록과 저자 자격
- 실험 기록(설정·결과·변경 이유)을 남긴다(`data-analysis`의 결과 기록 규칙). 연구 부정 의혹 시 소명 근거가 된다.
- 저자 순서·자격은 기획 단계에서 공동연구자와 합의한다. 기여 없는 저자 추가·기여자 누락은 부당한 저자 표시다(`paper-writing/references/ai-and-integrity.md` §2).
